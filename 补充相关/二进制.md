## 1. **二进制数据的表示基础**

### 位操作运算符
```cpp
int a = 0b1101;  // C++14起支持二进制字面量
int b = 0xF;     // 十六进制

// 位操作运算符
int x = a & b;   // 与

```

## 2. **位域（Bit Fields）**

位域允许在结构体中指定成员占用的位数：

```cpp
struct BitFieldExample {
    // 位域声明
    unsigned int flag1 : 1;   // 1位
    unsigned int flag2 : 3;   // 3位
    unsigned int flag3 : 4;   // 4位
    unsigned int : 0;         // 强制对齐到下一个边界
    unsigned int value : 8;   // 8位
    unsigned int : 4;         // 未命名的填充位
};

// 使用示例
BitFieldExample bf;
bf.flag1 = 1;      // 只能存储0或1
bf.flag2 = 5;      // 0-7（3位最大值为7）
bf.value = 255;    // 0-255
```

## 3. **std::bitset**

```cpp
#include <bitset>
#include <iostream>

void bitsetExample() {
    std::bitset<8> bits1(0b11001100);  // 8位bitset
    std::bitset<8> bits2("11110000");
    
    // 访问和修改
    bits1[0] = 1;          // 设置最低位
    bool bit = bits1[7];   // 获取最高位
    bits1.set();           // 所有位置1
    bits1.reset();         // 所有位置0
    bits1.flip();          // 所有位取反
    
    // 统计和查询
    std::cout << "Count of 1s: " << bits1.count() << std::endl;
    std::cout << "Size: " << bits1.size() << std::endl;
    std::cout << "Any bit set? " << bits1.any() << std::endl;
    std::cout << "All bits set? " << bits1.all() << std::endl;
    
    // 转换为其他类型
    unsigned long ul = bits1.to_ulong();
    std::string str = bits1.to_string();
}
```

## 4. **二进制文件操作**

### 二进制读写
```cpp
#include <fstream>
#include <vector>

struct DataPacket {
    uint32_t id;           // 4字节
    float value;           // 4字节  
    uint8_t flags;         // 1字节
    uint8_t : 0;           // 填充到4字节边界
};

void writeBinaryFile() {
    std::ofstream file("data.bin", std::ios::binary);
    
    DataPacket packet{1, 3.14f, 0b10101010};
    
    // 直接写入内存表示
    file.write(reinterpret_cast<char*>(&packet), sizeof(DataPacket));
    
    // 写入原始数据
    std::vector<uint8_t> rawData = {0x00, 0x01, 0x02, 0xFF};
    file.write(reinterpret_cast<char*>(rawData.data()), rawData.size());
}

void readBinaryFile() {
    std::ifstream file("data.bin", std::ios::binary | std::ios::ate);
    
    if (file) {
        std::streamsize size = file.tellg();
        file.seekg(0, std::ios::beg);
        
        std::vector<char> buffer(size);
        file.read(buffer.data(), size);
        
        // 解析数据
        DataPacket* packet = reinterpret_cast<DataPacket*>(buffer.data());
        std::cout << "ID: " << packet->id << std::endl;
    }
}
```

## 5. **位掩码和标志位**

```cpp
enum class Permissions : uint8_t {
    READ    = 0b00000001,  // 1 << 0
    WRITE   = 0b00000010,  // 1 << 1
    EXECUTE = 0b00000100,  // 1 << 2
    DELETE  = 0b00001000,  // 1 << 3
    ALL     = READ | WRITE | EXECUTE | DELETE
};

class FileAccess {
private:
    uint8_t permissions;
    
public:
    void setPermission(Permissions perm, bool enabled) {
        if (enabled) {
            permissions |= static_cast<uint8_t>(perm);
        } else {
            permissions &= ~static_cast<uint8_t>(perm);
        }
    }
    
    bool hasPermission(Permissions perm) const {
        return (permissions & static_cast<uint8_t>(perm)) != 0;
    }
    
    void togglePermission(Permissions perm) {
        permissions ^= static_cast<uint8_t>(perm);
    }
};
```

## 6. **二进制数据序列化**

```cpp
#include <cstring>
#include <vector>

class BinarySerializer {
private:
    std::vector<uint8_t> buffer;
    size_t position = 0;
    
public:
    template<typename T>
    void write(const T& value) {
        const uint8_t* bytes = reinterpret_cast<const uint8_t*>(&value);
        buffer.insert(buffer.end(), bytes, bytes + sizeof(T));
    }
    
    void writeString(const std::string& str) {
        write<uint32_t>(str.length());
        buffer.insert(buffer.end(), str.begin(), str.end());
    }
    
    template<typename T>
    T read() {
        T value;
        std::memcpy(&value, buffer.data() + position, sizeof(T));
        position += sizeof(T);
        return value;
    }
    
    std::string readString() {
        uint32_t length = read<uint32_t>();
        std::string str(buffer.begin() + position, 
                       buffer.begin() + position + length);
        position += length;
        return str;
    }
    
    const std::vector<uint8_t>& getData() const { return buffer; }
};
```

## 8. **位数组实现（自定义）**

```cpp
class BitArray {
private:
    std::vector<uint32_t> data;
    size_t bits;
    
public:
    BitArray(size_t num_bits) : bits(num_bits) {
        size_t words = (num_bits + 31) / 32;
        data.resize(words, 0);
    }
    
    void set(size_t index, bool value) {
        size_t word_idx = index / 32;
        size_t bit_idx = index % 32;
        
        if (value) {
            data[word_idx] |= (1u << bit_idx);
        } else {
            data[word_idx] &= ~(1u << bit_idx);
        }
    }
    
    bool get(size_t index) const {
        size_t word_idx = index / 32;
        size_t bit_idx = index % 32;
        return (data[word_idx] >> bit_idx) & 1u;
    }
    
    void clear() {
        std::fill(data.begin(), data.end(), 0);
    }
    
    size_t count() const {
        size_t count = 0;
        for (auto word : data) {
            count += __builtin_popcount(word);  // GCC内置函数
        }
        return count;
    }
};
```

## 9. **实际应用示例：网络协议**

```cpp
// 模拟IP头结构
struct IPHeader {
    uint8_t version_ihl;     // 版本(4位) + 头部长度(4位)
    uint8_t tos;            // 服务类型
    uint16_t total_length;  // 总长度
    uint16_t identification;
    uint16_t flags_fragment; // 标志(3位) + 分片偏移(13位)
    uint8_t ttl;
    uint8_t protocol;
    uint16_t checksum;
    uint32_t src_addr;
    uint32_t dst_addr;
    
    // 提取位域信息
    uint8_t version() const { return version_ihl >> 4; }
    uint8_t ihl() const { return version_ihl & 0x0F; }
    bool dont_fragment() const { return (flags_fragment >> 14) & 1; }
};

// 解析二进制网络包
void parsePacket(const uint8_t* data, size_t length) {
    if (length >= sizeof(IPHeader)) {
        const IPHeader* header = reinterpret_cast<const IPHeader*>(data);
        
        std::cout << "Version: " << (int)header->version() << std::endl;
        std::cout << "Header Length: " << (int)header->ihl() * 4 << " bytes" << std::endl;
        std::cout << "Total Length: " << ntohs(header->total_length) << std::endl;
        std::cout << "Don't Fragment: " << header->dont_fragment() << std::endl;
    }
}
```

## 10. **最佳实践和注意事项**

1. **字节序问题**：
   - 使用`htonl()`, `ntohl()`等进行网络字节序转换
   - 对于文件存储，定义自己的字节序约定

2. **类型安全**：
   ```cpp
   // 使用类型别名提高可读性
   using Byte = uint8_t;
   using Word = uint16_t;
   using DWord = uint32_t;
   ```

3. **错误处理**：
   - 检查二进制读取是否成功
   - 验证数据完整性（校验和、CRC等）

4. **性能考虑**：
   - 使用内存映射文件处理大文件
   - 避免不必要的复制

5. **可移植性**：
   - 避免依赖特定平台的对齐方式
   - 显式处理字节序

这些是C++中处理二进制数据的主要技术。根据具体应用场景选择合适的工具和技术组合。



## 将任意进制的数转换为十进制 和 将十进制数转换为任意进制

```c++
#include <string>
#include <algorithm>

// 将任意进制的数转换为十进制
int convertToDecimal(const std::string& str, int base) {
int result = 0;
for (char c : str) {
result = result * base + (isdigit(c) ? c - '0' : c - 'a' + 10);
}
return result;
}

// 将十进制数转换为任意进制
std::string convertFromDecimal(int num, int base) {
std::string result;
do {
int remainder = num % base;
result += (remainder < 10) ? remainder + '0' : remainder - 10 + 'a';
num /= base;
} while (num != 0);
std::reverse(result.begin(), result.end());
return result;
}
```
