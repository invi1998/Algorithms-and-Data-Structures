在 C++ 中，类的构造函数可以通过初始化列表（member initializer list）或构造函数体内的赋值来初始化成员变量。但有些情况下，**必须**使用初始化列表，否则代码将无法编译或导致未定义行为。以下是必须使用初始化列表的几种情形：

---

### 1. 初始化 `const` 成员变量
`const` 成员变量在对象构造完成后就不能再被修改，因此必须在进入构造函数体之前完成初始化。初始化列表是唯一合法的初始化位置。

```cpp
class MyClass {
    const int x;
public:
    MyClass(int val) : x(val) {}  // 必须使用初始化列表
    // MyClass(int val) { x = val; } // 错误：x 是 const，不能赋值
};
```

---

### 2. 初始化引用成员变量
引用必须在定义时绑定到一个有效的对象，且之后不能改变绑定。因此，引用成员也必须在初始化列表中进行初始化。

```cpp
class MyClass {
    int &ref;
public:
    MyClass(int &r) : ref(r) {}  // 必须使用初始化列表
    // MyClass(int &r) { ref = r; } // 错误：ref 未初始化，且不能重新绑定
};
```

---

### 3. 调用基类构造函数，且基类没有默认构造函数
如果基类没有提供无参构造函数（即默认构造函数），派生类的构造函数必须在初始化列表中显式调用基类的某个带参构造函数。

```cpp
class Base {
public:
    Base(int x) {}  // 没有默认构造函数
};

class Derived : public Base {
public:
    Derived(int val) : Base(val) {}  // 必须显式调用 Base 的构造函数
    // Derived(int val) { } // 错误：试图隐式调用 Base()，但 Base 没有默认构造函数
};
```

---

### 4. 成员对象是类类型，且该类没有默认构造函数
与基类类似，如果成员变量是某个类的对象，且该类的类型没有默认构造函数，则必须在初始化列表中显式调用其构造函数。

```cpp
class Member {
public:
    Member(int x) {}  // 没有默认构造函数
};

class MyClass {
    Member m;
public:
    MyClass(int val) : m(val) {}  // 必须显式初始化 m
    // MyClass(int val) { m = Member(val); } // 错误：m 必须先构造再赋值，但默认构造不可用
};
```

---

### 补充说明
- 即使成员有默认构造函数，如果希望直接使用特定参数构造对象（而非先默认构造再赋值），也推荐使用初始化列表，这可以避免一次额外的默认构造和赋值操作，提高效率。
- 对于内置类型的成员（如 `int`、`double` 等），初始化列表和构造函数体内赋值的差别不大，但使用初始化列表更符合初始化语义。

总之，上述四种情况是 C++ 语法规定必须使用初始化列表的场景，否则编译器会报错。其他情况下，初始化列表是可选的，但通常建议优先使用它以获得更好的性能和代码一致性。



# explicit

以下是几个关于 C++ `explicit` 关键字的面试/笔试题，涵盖了基础概念、C++11 扩展以及常见陷阱，适合不同层次的考察。

---

### 题目 1：基础概念
**问题**：`explicit` 关键字的作用是什么？请举例说明在什么情况下必须使用它。

**答案**：  
`explicit` 用于修饰构造函数（C++98/03）或转换运算符（C++11 起），阻止编译器进行隐式类型转换。  
- 对于单参数构造函数，如果不加 `explicit`，编译器可以用该构造函数隐式地将参数类型转换为类类型。加上 `explicit` 后，只能显式调用（如直接初始化或强制转换）。  
- 示例：  
  ```cpp
  class A {
  public:
      explicit A(int) {}  // 禁止隐式转换
  };
  void func(A a) {}
  func(10);            // 错误：不能将 int 隐式转换为 A
  func(A(10));         // 正确：显式构造
  ```
  当构造函数可能被意外用于隐式转换而导致歧义或错误时，必须使用 `explicit` 加以限制。

---

### 题目 2：隐式转换与 explicit 的判别
**问题**：以下代码哪些行会导致编译错误？请解释原因。
```cpp
class Widget {
public:
    Widget(double d) {}          // 构造函数 1
    explicit Widget(int i) {}     // 构造函数 2
};

void takeWidget(Widget w) {}

int main() {
    takeWidget(3.14);   // ①
    takeWidget(42);     // ②
    takeWidget('a');    // ③
    takeWidget(Widget(100)); // ④
    return 0;
}
```

**答案**：  
- ① 合法：`3.14` 是 `double`，可通过构造函数 1 隐式转换为 `Widget`。  
- ② 非法：`42` 是 `int`，匹配构造函数 2，但构造函数 2 是 `explicit`，不能隐式转换，因此编译错误。  
- ③ 合法：`'a'` 是 `char`，可提升为 `int`，但匹配的是构造函数 1（`double`），因为 `char` 到 `double` 是可行的标准转换，且构造函数 1 非 explicit，所以隐式转换允许。  
- ④ 合法：显式构造 `Widget(100)` 调用 explicit 构造函数，然后传递给函数，这是显式调用，合法。

---

### 题目 3：C++11 扩展——explicit 转换运算符
**问题**：C++11 允许 `explicit` 修饰转换运算符。请指出以下代码的输出或编译结果，并解释。
```cpp
struct Foo {
    explicit operator int() const { return 42; }
    operator double() const { return 3.14; }
};

int main() {
    Foo f;
    int x = static_cast<int>(f);   // ①
    int y = f;                     // ②
    double z = f;                   // ③
    std::cout << x << " " << y << " " << z << std::endl;
    return 0;
}
```

**答案**：  
- ① 合法：`static_cast<int>(f)` 显式调用 explicit 转换运算符。  
- ② 非法：`int y = f;` 试图隐式将 `Foo` 转换为 `int`，但 `operator int()` 是 explicit，禁止隐式转换，编译错误。  
- ③ 合法：`operator double()` 是非 explicit 的，允许隐式转换，`z` 被初始化为 `3.14`。  
因此代码编译失败（② 错误），若注释掉②，则输出 `42 0 3.14`（注意 `y` 未定义）。

---

### 题目 4：多参数构造函数与 explicit（C++11 起）
**问题**：在 C++11 之前，`explicit` 只能用于单参数构造函数。C++11 允许 `explicit` 用于多参数构造函数。请判断以下代码的合法性，并说明理由。
```cpp
class Point {
public:
    explicit Point(int x, int y) : x_(x), y_(y) {}
private:
    int x_, y_;
};

void draw(Point p) {}

int main() {
    draw({10, 20});   // ①
    draw(Point(10, 20)); // ②
    Point p1 = {1, 2}; // ③
    Point p2(1, 2);    // ④
}
```

**答案**：  
- ① 非法：`draw({10,20})` 试图使用列表初始化进行隐式转换（从初始化列表到 `Point`），但构造函数是 explicit，禁止隐式转换。  
- ② 合法：显式构造 `Point` 对象后传递。  
- ③ 非法：拷贝初始化形式 `Point p1 = {1,2};` 会调用 explicit 构造函数吗？C++17 起规则有所调整，但通常这种初始化被视为“复制列表初始化”，会考虑 explicit 构造函数，如果构造函数是 explicit，则编译错误。实际上 C++11 标准中，复制列表初始化（如 `Point p = {1,2}`）会调用 explicit 构造函数吗？标准规定：复制列表初始化中，如果构造函数是 explicit，则不能用于隐式转换，因此错误。  
- ④ 合法：直接初始化，允许调用 explicit 构造函数。  
所以，① 和 ③ 非法，② 和 ④ 合法。

---

### 题目 5：explicit 与模板构造函数
**问题**：考虑以下模板类，其中有一个模板构造函数。`explicit` 会影响模板参数推导或隐式转换吗？分析代码中的调用。
```cpp
template<typename T>
class Wrapper {
public:
    template<typename U>
    explicit Wrapper(U&& u) : data_(std::forward<U>(u)) {}
private:
    T data_;
};

int main() {
    Wrapper<int> w1 = 42;      // ①
    Wrapper<int> w2(3.14);     // ②
    Wrapper<int> w3 = {10};    // ③
    Wrapper<int> w4{20};        // ④
}
```

**答案**：  
- ① 非法：`Wrapper<int> w1 = 42;` 是拷贝初始化，需要隐式转换，但模板构造函数是 explicit，禁止隐式转换。  
- ② 合法：直接初始化 `w2(3.14)`，显式调用 explicit 模板构造函数。  
- ③ 非法：`Wrapper<int> w3 = {10};` 是列表拷贝初始化，需要隐式转换，explicit 阻止。  
- ④ 合法：直接列表初始化 `w4{20}`，显式调用 explicit 构造函数。  
模板构造函数也可以被 `explicit` 修饰，其效果与非模板构造函数相同：禁止在隐式转换场景中使用。

---

### 题目 6：陷阱题——explicit 与默认构造函数
**问题**：判断以下代码是否正确，并解释原因。
```cpp
class Logger {
public:
    explicit Logger() = default;   // explicit 默认构造函数
    void log() const {}
};

void useLogger(Logger lg) {
    lg.log();
}

int main() {
    useLogger({});        // ①
    useLogger(Logger());  // ②
    Logger lg1 = {};      // ③
    Logger lg2;           // ④
    return 0;
}
```

**答案**：  
- ① 非法：`useLogger({})` 试图通过空花括号进行值初始化并隐式转换，但默认构造函数是 explicit，不能用于隐式转换。  
- ② 合法：`Logger()` 创建临时对象，然后传递给函数，这是显式构造。  
- ③ 非法：`Logger lg1 = {};` 是拷贝列表初始化，需要隐式转换，explicit 阻止。  
- ④ 合法：`Logger lg2;` 是默认初始化，直接调用 explicit 默认构造函数（因为这里没有赋值符号，是直接定义变量），explicit 不影响默认初始化。  
注意：`explicit` 默认构造函数在直接初始化（如 `Logger lg;` 或 `Logger{}`）中是允许的，但在拷贝初始化形式（如 `Logger lg = {};`）中禁止。



# 虚继承

### 虚基类与继承顺序

**代码分析**

cpp

```C++
#include <iostream>
using namespace std;

class VBase {
public:
    VBase() { cout << "VBase "; }
};

class Base1 : virtual public VBase {
public:
    Base1() { cout << "Base1 "; }
};

class Base2 : virtual public VBase {
public:
    Base2() { cout << "Base2 "; }
};

class Derived : public Base1, public Base2 {
public:
    Derived() { cout << "Derived "; }
};

int main() {
    Derived d;
    return 0;
}
```



**问题**：程序输出是什么？

**答案**：

text

```
VBase Base1 Base2 Derived
```



**解析**：
虚基类的构造函数优先于非虚基类调用，且在整个继承体系中只构造一次。构造顺序：

1. 先调用虚基类`VBase`的构造函数（即使它在继承列表后面）。
2. 然后按派生类继承列表顺序调用非虚基类的构造函数：先`Base1`，后`Base2`。
3. 最后执行派生类`Derived`的构造函数体。
   （析构顺序相反。）
4. Base1、Base2 都是 virtual public VBase。虚继承会让 Derived 里只保留 一份共享的 VBase 子对象，不会各自拷贝一份。所以构造 Derived d;（见 main.cpp:79）时顺序是：先构造这唯一的一份虚基类 VBase，再构造 Base1、Base2，最后 Derived，即 VBase Base1 Base2 Derived。





### 函数遮蔽（非虚函数）

**代码分析**

cpp

```c++
#include <iostream>
using namespace std;

class Base {
public:
    void func() { cout << "Base::func()" << endl; }
    void func(int) { cout << "Base::func(int)" << endl; }
};

class Derived : public Base {
public:
    void func() { cout << "Derived::func()" << endl; }
};

int main() {
    Derived d;
    d.func();
    d.func(10);   // 此行能否编译通过？
    return 0;
}
```



**问题**：程序能否编译通过？如果能，输出是什么？如果不能，请说明原因。

**答案**：
编译错误：`'func'`不接收1个参数。
原因：派生类中定义了`func()`（无参），它会**隐藏**基类中所有名为`func`的函数（包括重载版本）。因此，通过派生类对象调用`func(int)`时，编译器只看到派生类中的`func()`，找不到匹配的`func(int)`，导致编译失败。

**拓展**：如果想调用基类的`func(int)`，可以使用`using Base::func;`在派生类中引入基类的所有重载，或者通过`d.Base::func(10);`显式指定作用域。



### 函数遮蔽与虚函数

**代码分析**

cpp

```c++
#include <iostream>
using namespace std;

class Base {
public:
    virtual void show() { cout << "Base show" << endl; }
    void display() { cout << "Base display" << endl; }
};

class Derived : public Base {
public:
    void show() override { cout << "Derived show" << endl; }
    void display() { cout << "Derived display" << endl; }
};

int main() {
    Base* p = new Derived();
    p->show();
    p->display();
    delete p;
    return 0;
}
```



**问题**：程序的输出是什么？

**答案**：

text

```
Derived show
Base display
```



**解析**：

- `show()`是虚函数，通过基类指针调用时发生动态绑定，实际调用派生类的覆盖版本。
- `display()`是非虚函数，静态绑定，根据指针类型（`Base*`）调用基类的版本。派生类的`display()`虽然同名，但只是隐藏了基类的同名函数，并不影响通过基类指针的调用。



### ''虚函数与默认参数

**代码分析**

cpp

```
#include <iostream>
using namespace std;

class Base {
public:
    virtual void func(int x = 10) { cout << "Base::func() x=" << x << endl; }
};

class Derived : public Base {
public:
    void func(int x = 20) override { cout << "Derived::func() x=" << x << endl; }
};

int main() {
    Base* p = new Derived();
    p->func();
    delete p;
    return 0;
}
```



**问题**：程序输出是什么？请解释默认参数的绑定时机。

**答案**：

text

```
Derived::func() x=10
```



**解析**：
虚函数的默认参数是静态绑定的，即根据指针（或引用）的静态类型决定。此处 `p` 的静态类型是 `Base*`，因此使用 `Base::func` 的默认参数 `10`。但函数调用本身是动态绑定，所以实际执行的是 `Derived::func`，但传入的参数是基类版本的默认值 `10`。
